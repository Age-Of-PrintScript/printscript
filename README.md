# PrintScript
This is the main repo for the interpreter of PrintScript


## Convenciones de código

### Formato de los distintos elementos 

- **Clases**: Pascal Case ('HelloWorld')
- **Métodos y variables**: Camel Case ('helloWorld')
- **Constantes**: Upper Snake Case ('HELLO_WORLD')
- **Imports**: sin wildcards en los imports ('import x.*')

### Otras reglas

- Nombres descriptivos tanto para los métodos como para las variables
- Sín números mágicos (números sin definición dentro del código)
